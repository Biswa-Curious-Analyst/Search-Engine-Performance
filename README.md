# Search-Engine-Performance
Performed analysis of the search engine dataset to predict the certifications- in- demand
QUERY; search-engine-traffic dataset containing information about user's search performance for certain certifications & money- advertisers pay for cost per click.
TOOLS; a) analysed the whole dataset & prepared different pivot tables in MS-Excel for better calculative insights.
b) imported this into SQL and prepared main table & lookup tables and run the ERR to develop a dynamic model.
c) executed the dynamic model into poerBI to find hidden insights of the dataset
INSIGHTS; translated complex metrics into actionable insights that improved user journeys and business outcomes.
